# One-click deploy (do this now)

## 1. Render (browser should have opened)

If not, open:
https://dashboard.render.com/blueprint/new?repo=https://github.com/shivamgiri068/TaskFlow

1. Sign in with GitHub.
2. When asked for **MONGODB_URI**, paste the value from `DEPLOY_SECRETS.txt` in this folder.
3. **JWT_SECRET** is auto-generated by Render (or paste from `DEPLOY_SECRETS.txt`).
4. Click **Apply** and wait ~3 minutes.

Your live URL will look like: `https://taskflow-xxxx.onrender.com`

## 2. MongoDB Atlas (if deploy fails on DB)

1. https://cloud.mongodb.com → your cluster
2. **Network Access** → **Add IP Address** → **Allow Access from Anywhere**
3. Redeploy on Render

## 3. Test

```bash
curl https://YOUR-RENDER-URL.onrender.com/
```

Expected: `TaskFlow API is running`
